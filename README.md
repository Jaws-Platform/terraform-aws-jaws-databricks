# terraform-aws-jaws-databricks

Terraform modules for Databricks on AWS with Unity Catalog: the account baseline, workspaces in a customer-managed VPC, isolated catalogs, governed compute and read-only dataset sharing

The modules are on their way: this is the initial scaffold. Once the first
version is released they are published on the
[Terraform Registry](https://registry.terraform.io/modules/jwallace145/jaws-databricks/aws/latest)
as `jwallace145/jaws-databricks/aws`.
